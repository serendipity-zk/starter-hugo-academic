TraceLab provides real-world coding agent traces collected from Claude Code and Codex. The dataset captures multi-step agent sessions, LLM requests, tool calls, cache behavior, latency distributions, and workload characteristics for studying agentic AI systems.

TraceLab is integrated into [NVIDIA AIPerf](https://docs.nvidia.com/aiperf/tutorials/datasets-inputs/replay-trace-lab-agentic-coding-traces), which can replay TraceLab sessions to benchmark serving systems under real agentic coding workloads.

Explore the dataset on the [project website](https://tracelab.cs.washington.edu/), or read the [paper](https://arxiv.org/abs/2606.30560) and [blog post](https://syfi.cs.washington.edu/blog/2026-06-25-tracelab/).
